# TempoGalicia v1.2.1 — corrección de iconos en Wolfram|Alpha

## Correcciones
- Los iconos **Meteocons** de Wolfram|Alpha se insertan ahora como **SVG locales dentro del HTML**, en vez de cargar imágenes SVG desde URL `data:`. Esto evita problemas de visualización en Android WebView sin habilitar JavaScript, acceso a archivos o solicitudes de imágenes externas.
- Se renombran los identificadores internos de cada SVG para que los gradientes y símbolos se rendericen correctamente cuando hay varios iconos en pantalla.
- La interpretación de Wolfram|Alpha comprueba también los títulos de los subapartados y, si están presentes, las descripciones de imágenes, además del contenido meteorológico textual.
- Los apartados de **condiciones actuales** y **previsión** muestran un icono «estado no especificado» cuando no existe evidencia suficiente para escoger un estado del cielo. No se inventan condiciones meteorológicas.
- Si un icono no está disponible en el paquete, aparece una representación de reserva visible.

## Compatibilidad
- Se conserva MeteoGalicia con sus iconos, selector de concello y selector de fuente.
- La conectividad, comprobaciones de red, widgets, notificaciones y configuración de Wolfram|Alpha no cambian.
- Siguen siendo necesarios un AppID autorizado para Full Results API y la aceptación de una traducción meteorológica parcial.

## Pruebas
La publicación se condiciona a superar `testDebugUnitTest`, `assembleDebug`, `lintDebug` y `assembleRelease` en GitHub Actions. Se incluyen pruebas de regresión de iconos incrustados, condiciones desconocidas, títulos de subapartados e independencia de identificadores SVG.

## Licencia e instalación
Iconos de [Meteocons (Bas Milius)](https://github.com/rodrigosambadesaa/weather-icons), licencia MIT incluida en el APK. El APK de GitHub se firma para **pruebas** con el keystore de depuración salvo que existan credenciales de producción: no equivale a una distribución firmada para Google Play y puede no actualizar instalaciones de firma distinta.

La interacción real con Wolfram|Alpha debe comprobarse en el dispositivo con un AppID válido; estas pruebas automatizadas no incluyen llamadas reales a la API.
