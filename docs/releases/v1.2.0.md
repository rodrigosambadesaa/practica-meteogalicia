# TempoGalicia v1.2.0 — iconos Meteocons en ambas fuentes

## Novedades
- Ilustraciones meteorológicas SVG de **Meteocons** integradas en los resultados de **MeteoGalicia y Wolfram|Alpha**.
- Incluye iconos para lluvia, nubes, sol, tormenta, niebla, nieve, granizo y otras condiciones reconocidas.
- MeteoGalicia usa iconos **orientativos** según la probabilidad de precipitación disponible; no se interpretan como observaciones directas de nubosidad.
- Wolfram|Alpha asocia iconos a condiciones mencionadas expresamente en los datos textuales; no inventa iconos para valores desconocidos.
- Los iconos se incluyen en el APK sin peticiones a servidores externos. Se mantienen la conectividad, los selectores, las notificaciones y los widgets existentes.

## Créditos y licencia
Los iconos proceden de [rodrigosambadesaa/weather-icons](https://github.com/rodrigosambadesaa/weather-icons), basado en Meteocons de **Bas Milius** (MIT, © 2020–2022). La licencia completa se incluye en `app/src/main/assets/meteocons/LICENSE` y la atribución en `THIRD_PARTY_NOTICES.md`.

## Instalación y limitaciones
- **APK para instalación manual y pruebas**, generado desde GitHub Actions tras pruebas unitarias, compilación y Android Lint.
- Si no se proporcionan credenciales de firma de producción, el APK utiliza **firma de depuración**. No está firmado para Google Play; Android puede rechazar la actualización de una app instalada con una firma distinta.
- Wolfram|Alpha sigue necesitando un AppID autorizado para Full Results API y su traducción al español sigue siendo parcial.
- El proyecto no representa una aplicación oficial de MeteoGalicia.

Véase [documentación de integración](https://github.com/rodrigosambadesaa/practica-tiempo/blob/main/docs/WEATHER_ICONS.md).
